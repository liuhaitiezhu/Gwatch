### C51 → STM32 HAL 移植映射（本次总结）
| C51 | STM32 HAL |
|---|---|
| `#include "stc12c5a60s2.h"` | `#include "main.h"`（SFR 头整份丢） |
| `sbit LCD_CS = P0^3;` | `GPIO_TypeDef*` + `uint16_t pin` 宏 |
| `LCD_CS=0` | `HAL_GPIO_WritePin(port, pin, GPIO_PIN_RESET)` |
| `SPI_RW(byte)` 软件模拟 | `HAL_SPI_Transmit(&hspi1, &byte, 1, timeout)` |
| `delay_ms(n)` 空循环 | `HAL_Delay(n)` |
| `unsigned int`（**16 位**） | 必须显式 `uint16_t`/`uint32_t`（**32 位**，易踩） |
| `code` / `xdata` 内存限定符 | `const`（自动进 .rodata） |
| `_nop_()` (intrins.h) | `__NOP()` (CMSIS) |
| `P0=0; P2=0;` | 删（ARM 无端口整体赋值） |
| `void main()` | `int main(void)` |

- 51 版 bit-bang 速率：12 MHz 主频 ≈ 214 KB/s → 一帧 153600 B 要 **0.7 秒**（1.4 fps）；STM32 硬件 SPI @40 MHz = 5 MB/s，快约 23 倍 → **移植时不要直译 bit-bang**
- 51 版 `SPI_RW` 是 SCK 空闲低 + 上升沿采样 → **SPI Mode 0**（CPOL=Low, CPHA=1Edge）；MSB first。与工程 `spi.c` 现有配置一致
- 51 版每个字节都拉一次 CS。手册 §7.1.12 明确允许（CS 拉高即"暂停"，再拉低从断点续传），**合法但慢**；正确做法是一次事务只拉一次 CS（新驱动已这么做）
- 小端一致：C51 与 Cortex-M 都是小端，`color>>8 / color&0xFF` 拆字节逻辑可照搬
